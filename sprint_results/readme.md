## Values of 'p_ij' (i.e. score for each solution)

The term `p_ij` represents the **score** that team `i` receives for a specific problem instance `j`.

As a reminder, its value is determined by the outcome of the team's solution:

*   For a **feasible** solution, the score is `max(0, R - nb_ij)`, rewarding teams with fewer competitors who performed better (R=15).

*   An **unfeasible** solution scores 0 points.
